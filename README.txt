BY MARÍA BEAUTY & STORE – WEBSITE (VERSION 1)
===========================================

Inhalt:
- index.html: komplette Website mit Design, Text und WhatsApp-Buttons
- assets/maria-ilustracion.webp: Marias personalisierte Illustration

VORSCHAU AUF DEINEM PC
1. ZIP-Datei entpacken.
2. Doppelklick auf index.html.
3. Die Website öffnet sich im Browser. Internet ist nur für die optionalen Google-Schriftarten und WhatsApp nötig.

KOSTENLOS VERÖFFENTLICHEN MIT GITHUB PAGES
1. Auf github.com ein neues öffentliches Repository erstellen, z.B. by-maria-beauty-store.
2. index.html und den vollständigen Ordner assets in das Repository hochladen (NICHT nur die ZIP-Datei).
3. Settings > Pages > Build and deployment > Deploy from a branch wählen.
4. Branch main, Ordner /(root) auswählen und speichern.
5. Sobald GitHub Pages fertig bereitgestellt ist, wird die Adresse dort angezeigt, üblicherweise https://DEIN-BENUTZERNAME.github.io/by-maria-beauty-store/
